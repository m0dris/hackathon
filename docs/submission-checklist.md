# Комплектность сдачи

Основание: кейс «Умный город», страницы 7–13.

| Требование | Состояние | Следующий шаг |
| --- | --- | --- |
| Работающий бот MAX | Не подключён | Выданный токен, webhook и ссылка |
| Мобильный и веб-сценарий | Не проверен | Пройти `docs/demo.md` в обеих версиях |
| Репозиторий и commit hash | Репозиторий есть | После загрузки зафиксировать окончательный hash |
| README | Подготовлен | Проверить в окружении команды |
| Docker, `.dockerignore`, `.env.example` | Подготовлены | Холодная сборка, замер лимита 5 минут |
| Зависимости | Go и Java зафиксированы | Сохранить `go.sum` и `gradle.lockfile` |
| PDF-презентация | Публичная версия | Реальные ссылки и закрытый служебный слайд |
| Тестовые данные | Синтетические | Два тестовых аккаунта MAX |
| HTTPS-адрес API | Отсутствует | Разместить сервис, согласовать проверку gRPC |
| OpenAPI и DATA-API | HTTP-контракт и заготовка | Реальный адрес и схема платформы оценки |
| Тестовые логины и пароли | У бота их нет | Доступ к тестовым аккаунтам через закрытый канал |
| Рабочие секреты | Не опубликованы | Передать только жюри |

По странице 11 без презентации или возможности проверить сценарий в MAX решение не допускается к оценке. Главный незавершённый шаг: реальное подключение бота и HTTPS-сервера.

## Служебный первый слайд

Жюри нужны ссылка на бот, репозиторий и hash проверяемого кода, адрес API, учётные данные, параметры запуска и сценарий. В публичной версии указаны только имена параметров. Закрытую копию с рабочими значениями храните отдельно от GitHub. Согласуйте передачу с организаторами.

После загрузки сохраните `git rev-parse HEAD` в форме сдачи и закрытой презентации. После дедлайна не меняйте переданную версию без разрешения организаторов.
